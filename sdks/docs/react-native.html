React Native SDK Integration

Native KYC in your React Native / Expo app. Camera capture, liveness detection, and document verification built in.

Installation

npm 
npm install @cip/kyc-react-native

Peer Dependencies

The SDK requires expo-camera for camera access:

Shell 
# If using Expo
npx expo install expo-camera

# If using bare React Native
npm install expo-camera
npx pod-install # iOS only

Expo Setup

Add the camera plugin to your app.json / app.config.js:

JSON (app.json) 
{
  "expo": {
    "plugins": [
      [
        "expo-camera",
        {
          "cameraPermission": "CIP needs camera access to verify your identity."
        }
      ]
    ]
  }
}

Expo Go Limitation

Camera capture works in Expo Go for development. For production, use a development build (npx expo prebuild) or EAS Build.

Quick Start

TypeScript (JSX) 
import { CipKyc } from '@cip/kyc-react-native';

export function KycScreen() {
  return (
    <CipKyc
      apiKey="cip_live_your_api_key"
      sessionId="session-id-from-your-backend"
      onComplete={(result) => {
        console.log('KYC result:', result.status);
        navigation.goBack();
      }}
      onError={(err) => console.error(err)}
      onCancel={() => navigation.goBack()}
    />
  );
}

The <CipKyc /> component takes over the entire screen and manages the verification flow, camera permissions, step progression, and result display.

Branding

The React Native SDK supports the same branding options as the Web SDK, with RN-specific differences:

PropertyTypeDefaultNotes
primaryColorstring'#F28A17'Hex color string
backgroundColorstring'#0A0A0C'Hex color string
textColorstring'#F5F5F5'Hex color string
logostring''URL to logo image
companyNamestring'CIP'Shown in header
fontFamilystring'System'Uses system font by default. Pass a custom font name if loaded.
borderRadiusnumber12Number (not string) — React Native uses numeric border radius.

RN-specific: borderRadius is a number

Unlike the Web SDK which takes a CSS string ('12px'), the React Native SDK takes a plain number (12). Also, fontFamily defaults to 'System' (React Native system font) instead of a CSS font stack.

onStepComplete(step: string, data: any)

Step names: document_front, document_back, selfie, liveness, document_in_hand

onError(error: CipKycError)

Error codes: CAMERA_DENIED, CAMERA_UNAVAILABLE, NETWORK_ERROR, SESSION_EXPIRED, UNKNOWN_ERROR

onCancel()

Triggered after the user confirms cancellation via the native Alert dialog. Use this to navigate back in your app.

Step-by-Step Integration

1. Install and configure permissions

Shell 
npm install @cip/kyc-react-native
npx expo install expo-camera

2. Create a session on your backend

TypeScript 
// api.ts - Call YOUR backend which calls CIP
export async function createKycSession(): Promise<string> {
  const res = await fetch('https://yourapi.com/kyc/create-session', {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${userToken}` },
  });
  const { sessionId } = await res.json();
  return sessionId;
}

3. Render the CipKyc component

TypeScript (JSX) 
import React, { useState, useEffect } from 'react';
import { View, ActivityIndicator } from 'react-native';
import { CipKyc } from '@cip/kyc-react-native';
import { createKycSession } from './api';

export function KycScreen({ navigation }) {
  const [sessionId, setSessionId] = useState<string | null>(null);

  useEffect(() => {
    createKycSession().then(setSessionId);
  }, []);

  if (!sessionId) {
    return (
      <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
        <ActivityIndicator size="large" color="#F28A17" />
      </View>
    );
  }

  return (
    <CipKyc
      apiKey="cip_live_your_api_key"
      sessionId={sessionId}
      onComplete={(result) => {
        console.log('KYC done:', result.status);
        if (result.status === 'approved') {
          navigation.replace('Dashboard');
        } else {
          navigation.replace('KycResult', { status: result.status });
        }
      }}
      onError={(err) => {
        console.error('KYC error:', err);
      }}
      onCancel={() => navigation.goBack()}
    />
  );
}

4. Handle completion

Navigate the user based on the result. Always verify the result server-side from your backend.

Platform-Specific Notes

iOS
Android
Expo

iOS: Info.plist Camera Permission

Add the camera usage description to your ios/YourApp/Info.plist:

XML (Info.plist) 
<key>NSCameraUsageDescription</key>
<string>CIP needs camera access to verify your identity through document capture and selfie.</string>

iOS Notes

  • Camera permission prompt appears automatically when the SDK starts
  • If the user denies, the SDK shows a permission request screen with a button
  • Minimum iOS version: 13.0
  • Works with both Face ID and Touch ID devices

Android: AndroidManifest Camera Permission

Add to android/app/src/main/AndroidManifest.xml:

XML (AndroidManifest.xml) 
<uses-permission android:name="android.permission.CAMERA" />
<uses-feature android:name="android.hardware.camera" android:required="false" />
<uses-feature android:name="android.hardware.camera.front" android:required="false" />

Android Notes

  • Minimum SDK version: 21 (Android 5.0)
  • Runtime permission is handled by expo-camera
  • Works on both physical devices and emulators (with virtual camera)

Expo: app.json Camera Plugin

JSON (app.json) 
{
  "expo": {
    "plugins": [
      [
        "expo-camera",
        {
          "cameraPermission": "We need your camera to verify your identity."
        }
      ]
    ],
    "ios": {
      "infoPlist": {
        "NSCameraUsageDescription": "CIP needs camera access to verify your identity."
      }
    },
    "android": {
      "permissions": ["CAMERA"]
    }
  }
}

Expo Notes

  • Works with Expo SDK 49+ and expo-camera 14+
  • Use npx expo prebuild for a development build if Expo Go has issues
  • EAS Build handles permissions automatically

Exchange Integration Example

Here is how a VASP exchange app (like Paiso) integrates the CIP KYC SDK into its onboarding flow:

TypeScript (JSX) - Exchange App 
import React, { useState, useCallback } from 'react';
import { View, Text, TouchableOpacity, StyleSheet } from 'react-native';
import { CipKyc, CipKycResult } from '@cip/kyc-react-native';
import { useAuth } from './hooks/useAuth';

type Screen = 'prompt' | 'kyc' | 'done';

export function OnboardingKycScreen({ navigation }) {
  const { user, refreshUser } = useAuth();
  const [screen, setScreen] = useState<Screen>('prompt');
  const [sessionId, setSessionId] = useState<string | null>(null);

  const startKyc = useCallback(async () => {
    // Your exchange backend creates a CIP session
    const res = await fetch('https://api.yourexchange.com/kyc/session', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${user.token}`,
        'Content-Type': 'application/json',
      },
    });
    const { sessionId } = await res.json();
    setSessionId(sessionId);
    setScreen('kyc');
  }, [user]);

  const handleComplete = useCallback((result: CipKycResult) => {
    if (result.status === 'approved') {
      refreshUser(); // Refresh user profile with new KYC status
      navigation.replace('Home');
    } else {
      setScreen('done');
    }
  }, [navigation, refreshUser]);

  if (screen === 'kyc' && sessionId) {
    return (
      <CipKyc
        apiKey={process.env.EXPO_PUBLIC_CIP_API_KEY}
        sessionId={sessionId}
        branding={{
          primaryColor: '#F28A17',  // Match your exchange theme
          companyName: 'YourExchange',
          borderRadius: 12,
        }}
        onComplete={handleComplete}
        onError={(err) => console.error(err)}
        onCancel={() => setScreen('prompt')}
      />
    );
  }

  // Prompt screen or done screen...
  return (
    <View style={styles.container}>
      <Text style={styles.title}>
        {screen === 'done' ? 'Verification Submitted' : 'Verify Your Identity'}
      </Text>
      <Text style={styles.subtitle}>
        {screen === 'done'
          ? 'We are reviewing your documents. This usually takes a few minutes.'
          : 'Complete KYC to unlock trading and withdrawals.'}
      </Text>
      {screen === 'prompt' && (
        <TouchableOpacity style={styles.button} onPress={startKyc}>
          <Text style={styles.buttonText}>Start Verification</Text>
        </TouchableOpacity>
      )}
    </View>
  );
}

Troubleshooting

Camera not working

  • Ensure expo-camera is installed and the Expo config plugin is added
  • On physical devices: check Settings > Privacy > Camera for permission
  • On simulators: camera may not be available. Use a physical device for testing.
  • Run npx expo prebuild --clean if permissions are not being applied

expo-camera version mismatch

Common Error: expo-camera version incompatible

If you see version mismatch errors, ensure you install expo-camera using npx expo install expo-camera (not npm install). This ensures the correct version for your Expo SDK.

"Cannot find module" errors

  • Clear Metro bundler cache: npx expo start --clear
  • Delete node_modules and reinstall: rm -rf node_modules && npm install
  • For bare RN: run npx pod-install after installing

Permission denied on Android

  • Ensure CAMERA permission is in AndroidManifest.xml
  • On Android 13+, camera permission requires runtime request (handled by expo-camera)
  • Check the user has not permanently denied camera. If so, redirect to app settings.

Blank screen on component mount

  • Verify apiKey and sessionId are not empty strings
  • Check network connectivity to the CIP API
  • Look at the React Native console for error messages
  • Ensure the session has not expired (30-minute timeout)
