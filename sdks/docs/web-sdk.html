Web SDK Integration

Embed KYC directly in your web app — no redirects. Full control over branding and UX.

Installation

npm 
npm install @cip/kyc-web-sdk
yarn 
yarn add @cip/kyc-web-sdk
CDN 
<script src="https://cdn.cip.pk/sdk/kyc-web/latest/cip-kyc.min.js"></script>

Quick Start

Get KYC running in 5 lines of code:

TypeScript 
import { CipKyc } from '@cip/kyc-web-sdk';

const kyc = new CipKyc({
  apiKey: 'cip_live_your_api_key',
  sessionId: 'session-id-from-your-backend',
  onComplete: (result) => console.log('KYC done:', result),
  onError: (err) => console.error('KYC error:', err),
});

await kyc.start();

That is all you need. The SDK creates a fullscreen overlay, walks the user through document capture and selfie, and fires onComplete when done.

Events / Callbacks

onComplete(result: CipKycResult)

Fired when the entire verification flow completes (all steps done). The SDK auto-destroys after this.

TypeScript 
// CipKycResult shape
{
  sessionId: "a1b2c3d4-...",
  status: "approved" | "rejected" | "pending",
  kycStatus: "approved",      // raw status from server
  riskTier: "low",             // "low" | "medium" | "high"
  customerId: "cust-...",      // CIP customer ID or null
  data: {
    fullName: "Ahmed Khan",
    cnicNumber: "42101-1234567-8",
    dateOfBirth: "1995-03-15",
    gender: "male",
    address: "House 12, Street 5, Islamabad",
    faceMatchScore: 0.97,
    livenessScore: 0.99,       // only for advanced verification
  }
}

onStepComplete(step: string, data: any)

Fired after each individual step. Use this for progress tracking.

TypeScript 
// Step names: "document_front", "document_back", "selfie", "liveness", "document_in_hand"

onStepComplete: (step, data) => {
  console.log(`Step ${step} done`, data);

  // data shape for document steps:
  // { passed: true, data: { ocrName: "...", ocrCnic: "..." }, quality: { score: 0.95, issues: [] } }

  // data shape for selfie step:
  // { passed: true, data: { faceMatchScore: 0.97 }, quality: { score: 0.92, issues: [] } }

  // data shape for liveness step:
  // { passed: true, data: { livenessScore: 0.99, blinkDetected: true, headTurnDetected: true } }
}

onError(error: CipKycError)

Fired on any error. The SDK shows a retry/cancel UI automatically.

TypeScript 
// CipKycError shape
{
  code: "CAMERA_DENIED",           // error code
  message: "Camera access denied",  // human-readable message
  step: "selfie"                    // which step failed (optional)
}

// Common error codes:
// CAMERA_DENIED       - User denied camera permission
// CAMERA_UNAVAILABLE  - No camera found
// NETWORK_ERROR       - API request failed
// SESSION_EXPIRED     - Session timed out
// UNKNOWN_STEP        - Internal SDK error
// UNKNOWN_ERROR       - Unexpected error

onCancel()

Fired when the user confirms cancellation. The SDK auto-destroys.

Step-by-Step Integration

1. Install the SDK

Shell 
npm install @cip/kyc-web-sdk

2. Create a session on your backend

Node.js 
// Express route: POST /api/kyc/start
app.post('/api/kyc/start', async (req, res) => {
  const response = await fetch('https://api.cip.pk/api/v1/kyc-sessions', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.CIP_TOKEN}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      external_ref: req.user.id,
      customer_name: req.user.name,
      customer_cnic: req.user.cnic,
    }),
  });
  const session = await response.json();
  res.json({ sessionId: session.session_id });
});

3. Pass session ID to SDK and start

TypeScript 
import { CipKyc } from '@cip/kyc-web-sdk';

async function startKyc() {
  // 1. Get session from YOUR backend
  const res = await fetch('/api/kyc/start', { method: 'POST' });
  const { sessionId } = await res.json();

  // 2. Create and start the SDK
  const kyc = new CipKyc({
    apiKey: 'cip_live_your_key',
    sessionId,
    onComplete: (result) => {
      if (result.status === 'approved') {
        showSuccess('Identity verified!');
        refreshUserProfile();
      } else {
        showMessage('Verification is ' + result.status);
      }
    },
    onError: (err) => console.error('KYC error:', err),
    onCancel: () => console.log('User cancelled KYC'),
  });

  await kyc.start();
}

4. Handle completion

When onComplete fires, the SDK has already cleaned up its UI. Use the result to update your application state. Always verify the result server-side by calling GET /api/v1/kyc-sessions/{session_id} from your backend.

Advanced Usage

Mounting into a Specific Container

Instead of a fullscreen overlay, mount the SDK into a specific DOM element:

HTML + TypeScript 
<!-- Your page -->
<div id="kyc-container" style="width: 100%; max-width: 600px; height: 700px;"></div>

<script>
const kyc = new CipKyc({
  apiKey: 'cip_live_...',
  sessionId: '...',
  containerId: 'kyc-container',  // Mount here instead of overlay
  onComplete: (result) => { /* ... */ },
});
kyc.start();
</script>

Destroying / Cleaning Up

If you need to remove the SDK before the user completes (e.g., navigating away):

TypeScript 
// Manual cleanup
kyc.destroy();

// In React, clean up on unmount:
useEffect(() => {
  const kyc = new CipKyc({ /* config */ });
  kyc.start();
  return () => kyc.destroy();
}, []);

Important

After calling destroy(), the instance cannot be reused. Create a new CipKyc instance if you need to start again.

Session Resumption

If a user closes the page mid-verification, you can resume by creating a new SDK instance with the same sessionId. The SDK automatically skips already-completed steps.

TypeScript 
// Resume an existing session
const kyc = new CipKyc({
  apiKey: 'cip_live_...',
  sessionId: existingSessionId, // Same session ID
  onComplete: (result) => { /* ... */ },
});
await kyc.start(); // Will skip completed steps automatically

MethodReturnsDescription

Troubleshooting

Camera not working

  • Ensure the page is served over HTTPS. Browsers block camera access on HTTP (except localhost).
  • Check browser permissions: the user must allow camera access when prompted.
  • On mobile browsers, ensure no other app is using the camera.

CORS errors

  • The CIP API allows requests from any origin with a valid API key.
  • If using a custom apiBaseUrl, ensure CORS headers are configured on your proxy.
  • Do not call the CIP API directly from the browser without the SDK — use the SDK which handles auth correctly.

WebView compatibility

  • If embedding in a WebView (iOS/Android), ensure javaScriptEnabled and allowsInlineMediaPlayback are set.
  • On iOS, add NSCameraUsageDescription to Info.plist.
  • On Android, add CAMERA permission to AndroidManifest.xml.

SDK not loading

  • Verify the apiKey is valid and not revoked.
  • Check the sessionId is correct and the session has not expired.
  • Check the browser console for error messages.
  • Ensure the SDK package version is up to date.
